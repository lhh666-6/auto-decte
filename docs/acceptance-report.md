# Demo 自动化验收报告

- 日期：2026-07-12
- 分支：`phase-6-acceptance`
- 范围：P0–P5 软件功能组合验收
- 数据：仅合成、非敏感测试数据

## 已验证

- 无 OCR、无 AI 的图片导入、人工确认、查询、追溯和 XLSX 导出闭环。
- 原始证据 SHA-256 去重且不被静默覆盖。
- 人工更正追加 RecordVersion，保留历史版本和 before/after 审计。
- 图像模糊检测、二维码优先分类、透视校正和字段裁切。
- 数字格和 OMR 产生候选与置信度，只增 RecognitionAttempt，不覆盖人工值。
- 必填、范围、数量闭合、主数据、重复、版本、重新导出和映射规则。
- AI 关闭不阻断核心流程；AI 建议严格要求证据与人工确认并独立保存。
- 相似检索只返回参考记录，不参与精确统计或事实修改。
- XLSX 包含正式数据、异常与复核、汇总、导出说明，并可反查表单、版本、证据和事件。

## 自动化证据

质量门命令：

```powershell
uv run python -m pytest -q
uv run python -m ruff check .
uv run python -m mypy app config
```

组合验收测试覆盖二维码分类、数字候选、规则校验、人工确认、AI 关闭、相似检索、XLSX
导出和反向追溯。最终精确测试数量和静态检查结果以 `PROGRESS.md` 的 P6 记录为准。

## 尚不能声明达到的指标

以下指标缺少企业真实样张或现场数据，当前没有证据证明达标：

- 30–50 张技术集的自动分类正确率、图像质量合格率、数字准确率和整单正确率。
- 100–300 张现场试点的平均处理时间、错误自动放行率和财务处理时间下降比例。
- 三种真实表单的定位点、字段坐标和混淆数字分布。
- 真实录音绑定成功率、转写质量和企业外部 AI 授权结果。

## 现场验收所需输入

1. 三种冻结版本表单及字段坐标。
2. 30–50 张脱敏技术样张与双人录入金标准。
3. 企业工资、产量、质量 XLSX 模板。
4. 员工、工单、产品和工序测试主数据。
5. 允许用于验收的录音样例和授权规则。

收到上述输入后，在 `tests/golden/` 建立不入公共仓库的受控数据集，运行准确率与性能脚本，
再填写真实指标并决定是否进入 100–300 张现场试点。
