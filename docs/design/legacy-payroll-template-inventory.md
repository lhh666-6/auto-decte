# 历史工资表与模板族映射

> 分析日期：2026-07-13。原始 `.xls/.xlsx` 文件仅以只读方式检查，未被系统修改、转换或写回。

## 结论

现有表单不是一种“任意纸张识别”问题，而是四个稳定的工业记录模式。首版模板设计器应以这四类为可克隆种子；每个具体岗位在其基础上配置字段、单价说明、固定行数和规则。

| 种子模板键 | 适用场景 | 固定核心字段 |
|---|---|---|
| `PAYROLL_HOURLY` | 计时工、叉车人员 | 日期、姓名、上班时间段、工作小时、班次、考评、事实说明、五项考核 |
| `PAYROLL_STANDARD_PIECE` | 炭化、蒸煮、竹丝装架、装架组等“分类单价 + 数量”岗位 | 日期、班次、姓名、计价分类、单价、数量、合计、备注、考核 |
| `PAYROLL_FIXED_PRODUCTION_GRID` | 热压、开片/光刨等带固定生产明细行的岗位 | 日期、班组、班次、产品/规格/等级、数量、单价、工资、扣款、固定 `line_01`–`line_10` |
| `PAYROLL_EQUIPMENT_PROCESS` | 油炉、设备工序及带过程检查扣款的岗位 | 日期、人员、班次、检查项目、工艺分类、数量、扣款、备注 |

## 模板设计约束

- 生产明细使用固定行：首版采用 `line_01` 至 `line_10`，不支持工人现场增行。
- 班次、品质等级和考核项优先设计为 OMR 勾选区或受控枚举，不保留自由涂写。
- 单价和考核标准属于发布模板版本的固定说明区，不让工人在纸面填写或通过 OCR 改写。
- 计件数量、姓名、日期、设备台位、备注和异常说明属于字段区；每一字段有稳定 `field_key` 与裁切坐标。
- 每张打印纸自动携带模板 QR；推荐同时生成 `SHEET` 纸张实例码，防止同一纸张重新拍照后重复入库。

## 当前边界

所有读取到的业务表工作表均没有可复用的 Excel 公式；它们是纸面/录入布局参考，而不是系统的计算规则来源。单价、工资和扣款的确定性计算将在模板规则和导出阶段重新声明、测试和版本化，不能把历史格式中的人工解释直接当作可执行规则。

本机对老 `.xls` 的只读解析采用 LibreOffice 的隔离用户配置转换；未来正式“导入旧表”功能不得依赖 Excel COM 自动化，也不得修改用户原文件。
