### 节省 Token 和验收成本的强制规则

- 不扫描整个仓库，只读最终计划和当前 Task 列出的相关文件。
- 已有测试记录且本轮未修改的简单功能直接视为基线，不重新研究、不重复实现、不重复人工验收。
- 每个 Task 只运行相关测试；共享领域、迁移、公共 API、二维码或导出结构变化时才扩大到受影响的集成测试。
- 文案、按钮、空状态、导航高亮等简单修改只做组件测试和一次浏览器冒烟检查，不跑纸张闭环。
- 十个模板全部做结构化自动测试；实物闭环只验收计时工、蒸煮或炭化两拼、开片横向复杂表。
- 完整 Python 回归、Ruff、mypy、前端全测和生产构建只在 Task 16 统一运行一次。
- 同一个通过结果只记录一次；没有相关代码变化或失败证据时，不重复截图、日志和测试统计。
