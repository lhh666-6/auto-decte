# 后续任务

最后更新：2026-07-17

状态：前端重建任务 1—16 已完成；以下仅列真实未完成项，均需新的范围确认或后端授权。

目标分支：`modular-architecture`

## 第一优先级：重新拍照的永久证据关联

这是当前唯一明确的业务闭环硬阻塞。

现有 `POST /api/v1/imports` 会为新照片创建新表单，不能把新照片永久绑定为 `RECAPTURE_REQUIRED` 原表单的 replacement evidence。纯前端已完成待重拍页面、旧证据展示、退回原因和限制说明，但不能伪造新旧关系。

独立后端任务必须同时提供：

- 为原表单提交 replacement evidence 的生产接口；
- 使用新证据运行重新识别，并返回可查询任务；
- 永久保存 old/new evidence linkage；
- 为替换、重新识别和关联结果写入不可变审计事件；
- 补齐 API、存储、并发、失败回滚、权限和前端契约测试。

在该接口完成前，前端不得显示“已替换原照片”或“追溯关系已保存”，也不得使用浏览器内存或 `localStorage` 冒充持久化。

## 待人工决策的后续项目

这些项目未获本轮开发授权，不应顺手实现：

1. **现场样本量化验收**：收集 40–60 张真实企业样表，覆盖打印机、手机、光线、折痕、倾斜、缩放和二维码污损，记录分类、校正、裁片、识别和人工审核结果。
2. **生产 Worker 闭环**：将 `FORM_IMPORT`、`FORM_RECOGNITION`、`XLSX_EXPORT` 完整交由独立 Worker/Handler 消费，并补充运维、重试和失败恢复。
3. **模板包与纸张实例**：安全 ZIP 导入/导出、manifest/hash 校验、打印批次和每张纸唯一 `sheet_instance_id`。
4. **纸面模板产品化**：任意毫米尺寸、横竖方向、多联裁切、受约束业务小模块、毫米网格吸附和发布前物理尺寸校验。
5. **人员核验与中文 OCR**：工号与员工库匹配、未知工号的导出阻断、姓名人工核对，以及经样本证明后再接入中文 OCR。
6. **权限与桌面交付**：明确本地单用户和多用户部署边界，再决定身份切换、Tauri、相机/扫描仪、Windows 安装包和升级机制。
