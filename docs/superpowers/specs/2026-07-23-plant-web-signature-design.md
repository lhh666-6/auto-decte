# 厂长 Web 独立签字页设计

日期：2026-07-23

## 目标

将原厂长移动端的签字核对流程完整迁移到厂长 Web 工作区。厂长在电脑端查看整张竹丝电子表单、上游数据、生产签字、检测状态和申诉信息后，完成厂长签字或选择环节打回。

本功能不修改 `frontend/apps/web/src/mobile/**`，也不恢复厂长移动端权限。

## 页面入口与路由

- 独立路由：`/plant/production/:recordId`
- 生产看板中：
  - `current_stage === "PLANT_AUDIT"` 时显示主要按钮“查看并签字”。
  - 其他记录显示次要按钮“查看详情”。
- 页面提供返回生产看板的入口。

## 页面信息结构

页面按电脑宽屏布局展示以下内容：

1. 表单摘要
   - 表单编号
   - 笼号
   - 表单类型
   - 当前版本
   - 当前环节及状态
2. 流程进度
   - 分选表：分选签字 → 主管审核 → 厂长审核 → 已生效
   - 浸胶干燥联合表：浸胶记录 → 干燥联合签字 → 主管审核 → 厂长审核 → 已生效
3. 基础字段
   - 当前表单 `base_info` 全量只读展示
4. 只读上游表单
   - 联合表直接展示来源分选表基础字段和有效生产提交
   - 不跳转其他页面
5. 提交与签字记录
   - 显示工序、提交人、职务、服务器时间、版本和值
   - 有效版本和已失效历史版本均保留并清楚区分
6. 检测与申诉
   - 检测窗口状态、截止时间和剩余时间
   - 检测结论、文字记录、照片和录音留痕
   - 申诉内容及厂长审批入口
7. 厂长处理区
   - 审核说明，选填
   - 通过并签字
   - 选择环节打回

## 签字开放条件

“通过并签字”仅在以下条件全部满足时开放：

- 当前记录属于登录厂长所在工厂。
- `current_stage === "PLANT_AUDIT"`。
- 记录仍为可签状态，页面持有最新 `revision`。
- 检测已完成、检测窗口已自然结束，或厂长已执行“停止检测并提前签字”。
- 没有待厂长处理的检测申诉。

检测窗口处于 `OPEN` 或 `CLAIMED` 时：

- 禁止直接签字。
- 展示剩余时间。
- 提供“停止检测并提前签字”按钮。
- 点击后必须二次确认。
- 后台停止检测权限并向检测员发送统一消息，再刷新签字条件。

检测申诉处于 `APPEAL_SUBMITTED` 时：

- 不显示直接签字按钮。
- 厂长先审批申诉。
- 批准后按申诉目标环节回溯；驳回后重新加载记录状态。

## 签字交互

厂长填写可选“厂长审核说明”后点击“通过并签字”，进入二次确认框。

确认框展示：

- 表单编号和笼号
- 厂长审核结论
- 审核说明
- 当前登录厂长
- 所属工厂
- 当前记录版本
- 服务器签字时间将在提交时生成
- 签字将绑定数据摘要，不可代签

确认提交：

- 调用 `POST /api/v1/plant/records/{recordId}/audit`
- 请求带 `X-CSRF-Token`
- 每次确认生成稳定的 `Idempotency-Key`
- 请求体带 `expected_revision`、设备标识和：

```json
{
  "result": "APPROVED",
  "note": "厂长审核说明"
}
```

签字成功后：

- 显示成功反馈。
- 刷新详情。
- 当前状态变为已完成。
- 返回生产看板时展示最新状态。

并发或版本冲突时：

- 不重复提交新签字。
- 提示记录已更新。
- 重新加载详情和最新版本。

## 打回交互

详情页保留既有打回能力：

- 分选表可选择分选。
- 联合表可选择浸胶、干燥或两者。
- 原因必填。
- 请求继续使用 `expected_revision` 与 `Idempotency-Key`。
- 打回与“通过并签字”在视觉上分离，避免误操作。

## 后台读模型

扩展厂长生产详情响应，使一个请求提供签字页所需数据：

- 当前竹丝记录与版本
- 上游表单快照及提交记录
- 当前记录全部提交记录
- 检测窗口及剩余时间
- 检测结果、证据元数据和申诉状态
- 工资事实和纠错记录继续只读展示

写操作继续复用现有 Bamboo 服务：

- 厂长签字：`BambooProcessFacade.submit_stage`
- 提前终止检测：`BambooOperationsService.terminate_inspection`
- 申诉审批：`BambooOperationsService.decide_inspection_appeal`
- 选择环节打回：`BambooOperationsService.selective_return`

不建立第二套签字、检测或业务状态。

## 错误处理

- 无权限或跨厂：显示无权查看，不泄露记录内容。
- 检测窗口未结束：显示阻止原因和提前终止入口。
- 申诉待处理：引导先处理申诉。
- 版本冲突：刷新记录并要求重新核对。
- 重复幂等请求：返回第一次成功结果。
- 网络或服务异常：保留审核说明，允许厂长再次确认提交。

## 测试

后端测试覆盖：

- 详情响应包含上游、提交、检测窗口和证据。
- 跨厂详情不可见。
- 检测进行中不能签字。
- 提前终止检测后可以签字。
- 待审批申诉阻止直接签字。
- 签字的版本冲突与幂等行为。

前端测试覆盖：

- `PLANT_AUDIT` 记录显示“查看并签字”。
- 独立详情页展示整张表、上游、提交记录和检测状态。
- 检测进行中仅显示提前终止入口。
- 申诉待处理时仅显示申诉审批。
- 二次确认框展示身份、工厂和版本。
- 签字请求发送 CSRF、幂等键和 `expected_revision`。
- 签字成功后刷新为已完成。
- 打回功能继续可用。

## 验收标准

- 厂长能够完全在 Web 端完成原移动端厂长签字流程。
- 签字前能在当前页面核对完整上游、生产与检测信息。
- 检测两小时窗口、提前终止、24 小时申诉和回溯规则不被绕过。
- Web 与移动端工人、主管、检测员共用同一 Bamboo 数据和状态。
- `frontend/apps/web/src/mobile/**` 无改动。
