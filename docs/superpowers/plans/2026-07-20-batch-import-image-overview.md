# 批量导入、图片资产与图片总览

## 目标

在现有单图导入、任务状态、SHA-256 去重和不可变证据之上分两小步完成 V2 第 5 章，不改识别和审核事务。

## 第一步：后端批次与缩略图（当前）

1. 浏览器为一组上传生成批次编号；每张图仍调用独立导入任务，单张失败不回滚整批。
2. 任务负载持久记录批次编号、原文件名、格式、字节数和宽高；复用现有任务表，不新增重复批次表。
3. 原图继续按 SHA-256 完全去重；批次内重复项记录为“需要处理”，不会覆盖原证据。
4. 导入时生成不可变缩略图证据；原图、校正图、缩略图和字段裁片继续只存文件系统，数据库只存证据元数据。
5. 提供批次汇总和图片总览读取接口。

## 第二步：前端多图导入与三视图（后续）

1. 支持多选、拖拽和文件夹；前端固定 3 路并发。
2. 每张图片独立显示处理中、成功、需要处理或失败，并可单张重试。
3. 审核工作台提供任务视图、图片总览、导入批次；缩略图可直接进入现有左图右表审核页。

## 验证

- 当前只运行导入 API、证据存储和任务汇总定向测试及相关 Ruff/mypy。
- 前端步骤只运行新增导入/图片总览组件测试和 TypeScript。
- 不重复运行模板、审核确认、导出或完整套件。
