# 受控明细表网格 API 与设计器贯通

## 目标

让模板中的 `TABLE_GRID` 在后端、API 客户端和模板设计器之间完整保留并受控修改行数、列数和比例列宽。设计器不提供 HTML、脚本或自由绘制入口。

## 范围

1. 模板版本响应为静态元素返回 `rows`、`columns`、`column_weights`。
2. 增加静态元素的受控替换接口；沿用领域层的草稿/发布版限制。
3. TypeScript 模型和客户端完整往返表格参数。
4. 设计器列出已有明细表，并提供行数、列数、比例列宽设置。
5. 画布显示静态表格轮廓，便于确认当前编辑对象；本任务不开放其任意拖放或自由内容。

## 验证

- 模板 API 定向测试：表格参数读取、替换、非法参数、发布版不可修改。
- API 客户端定向测试：请求路径与负载。
- 设计器定向测试：选择表格、保存设置、错误时不伪造成功状态。
- 前端 TypeScript、相关 Ruff 与 mypy。

## 非目标

- 不新增自由 HTML、脚本或任意绘图。
- 不重做六个核心模板、字段设置、打印识别闭环、审核或导出测试。
- 不修改既有数据库内容或历史迁移。
