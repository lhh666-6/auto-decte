# 受控纸面字段元数据执行计划

## 目标

在六个核心版面落地前，把 V2 明确要求的填写约束变成可保存、可打印、可校验的数据，而不是仅写在标签文字里。

## 范围

- 数字格明确位数，打印器按配置绘制；
- 单选/多选明确选项组、固定选项和最大选择数；
- 姓名等系统带入字段明确来源字段，禁止作为自由手写字段；
- 异常说明明确条件必填表达式；
- 签字线明确签字角色；
- 历史字段记录缺少新键时继续按旧默认读取。

## 不在本任务

- 不建立六张成品模板；
- 不修改审核事务、识别算法或导出流程；
- 不迁移、不删除旧模板和旧数据。

## 验证

- 领域规则测试；
- 模板仓储 JSON 新旧兼容测试；
- 打印数字格位数测试；
- 相关 Ruff 与 mypy。
