# Web 转型阶段 3：业务建模与可视化流程

日期：2026-07-23

## 已实现

- 财务多轮业务梳理会话、来源引用和结构化规则草稿。
- 所有建议规则默认 `PROPOSED` 且不可执行。
- 财务确认后生成不可覆盖的业务逻辑基线版本。
- 六类结构化流程节点：表单、条件、角色确认、字段映射、通知、结束。
- 画布信息与业务图分开保存。
- 流程草稿、内容哈希、版本、管理员审核和按工厂启用。
- 厂长只读查看本厂已启用流程。

- 有效起点和结束节点；
- 不可达节点和悬空连线；
- 循环路径；
- 条件的真、假分支完整性；
- 表单版本已启用；
- 业务规则已经财务确认；
- 角色节点目标角色；
- 字段映射存在且类型一致；
- 工厂范围没有越权。
