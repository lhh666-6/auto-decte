# Web 转型阶段 2：电子表单与管理员启用

日期：2026-07-23
状态：实现完成，等待阶段提交

## 业务闭环

1. 财务在 `/finance/forms` 创建结构化电子表单草稿。
2. 草稿按修订号更新，可添加多个字段。
3. 财务提交后版本进入待管理员审核状态。
4. 管理员在 `/admin/form-approvals` 批准或退回。
5. 批准版本由管理员明确选择工厂后启用。
6. 厂长在 `/plant/forms` 只读查看本厂当前版本，并在
   `/plant/notifications` 留下知悉记录；未知悉不阻塞版本生效。
7. 本厂对应岗位通过原有移动端表单接口读取当前启用版本。

## 版本和数据规则

- `electronic_form_definitions` 保存稳定表单身份。
- `electronic_form_versions` 保存不可变内容版本和内容哈希。
- 只有 `DRAFT` 可编辑；提交、批准及启用后的版本均不可修改。
- 克隆会产生新的草稿版本，不覆盖旧版本。
- 同一表单、同一工厂只保留一个当前启用版本。
- 切换新版本只停用旧版本的当前入口，旧版本记录仍可读取。
- `form_plant_activations` 独立记录各工厂的启用、停用和退役状态。
- `management_notifications` 保存厂长通知和知悉时间。

## 权限和安全

- 财务负责创建、编辑和提交。
- 管理员负责审核、启用、停用、恢复和退役。
- 厂长只能查看本厂数据，不能跨厂或修改表单。
- 所有 Web 写请求验证页面可读 CSRF Cookie。
- 移动端路径和响应 Schema 不变，仅增加本厂启用版本的数据来源。
