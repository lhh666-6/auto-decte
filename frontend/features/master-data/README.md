# master-data

**Status:** Contract skeleton — TypeScript interfaces only.

Master data management UI. Admin interface for managing reference data:
form types, field definitions, validation rules, operator accounts, and
client/project configuration.

## Scope

- Form type catalogue (CRUD)
- Field definition editor
- Validation rule configuration
- Operator / role management
- Client and project settings

## Dependencies

- `@form-detection/api-client` — master data CRUD endpoints
- React + form library
