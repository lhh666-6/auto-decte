### 2.1 新建文件

**[frontend/apps/web/src/mobile/v3/ui/tokens.css](frontend/apps/web/src/mobile/v3/ui/tokens.css)**（60 行）

统一设计 token 变量，作为所有 V3 组件的单一权威来源：

```css
.mobile-v3-shell {
  /* Palette — 对齐设计规格 #176B5B */
  --brand: #176B5B; --brand2: #26804d; --brand-weak: #e6f2ed;
  --bg: #F4F7F6; --card: #FFFFFF; --text: #17211F;
  --sub: #66736b; --line: #dde4df; --muted: #eff2f0;
  --ok: #168a4d; --warn: #c77a0a; --danger: #c43f35; --blue: #2f67d8;

  /* Spacing */
  --space-xs:4px; --space-sm:8px; --space-md:12px;
  --space-lg:16px; --space-xl:20px; --space-2xl:24px;

  /* Typography */
  --font-display:25px; --font-heading:18px; --font-body:15px;
  --font-caption:13px; --font-label:12px; --font-micro:11px;

  /* Radius */
  --radius-sm:8px; --radius-md:12px; --radius-card:16px; --radius-sheet:22px;

  /* Touch targets */
  --touch-min:44px; --touch-btn:48px; --touch-primary:52px;

  /* Effects */
  --shadow: 0 8px 24px rgba(19,50,33,0.08);
  --shadow-heavy: 0 12px 32px rgba(19,50,33,0.12);
}
```

关键设计决策：
- **`--brand` 从 `#17653a` 微调至 `#176B5B`** — 仅 `+0x22(R) -0x06(G)`，肉眼不可察觉，对齐设计文档
- **`--bg` 从 `#f3f5f4` 微调至 `#F4F7F6`** — 同等亮度级，更清爽
- **新增 4 级间距 + 5 级字号 + 4 级圆角 + 3 级触摸目标 + 2 级阴影** — 覆盖文档全部规格

## 6. 实施方式

采用**多代理并行**策略，4 个后台代理同时修改：

| Agent | 职责 | 修改范围 |
|-------|------|---------|
| Shell+Login | Shell 导航 + 登录页 | `.mobile-v3-shell`、`.bamboo-v3-login` |
| Home+Profile+Sub | 首页 + 提交记录 + 个人页 | `.bamboo-v3-home`、`-profile`、`-list` |
| TaskList+JSX | 任务列表 + Bottom Sheet + JSX 分组 | `.bamboo-work-page`、`.field-group`、`BambooTaskListPage.tsx` |
| Detail+Form+Ops | 详情 + 阶段表单 + 操作面板 | `.bamboo-record-hero`、`-stage-form`、`-operation-card` |

每个代理独立修改非重叠 CSS 区域 + Token 替换，无需串行等待。
